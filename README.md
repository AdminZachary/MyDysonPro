# MyDysonPro

The SleepPause iOS and watchOS app is in [`SleepPause/`](SleepPause/).

GitHub Actions (`.github/workflows/build.yml`) builds it on the `xcode-27` runner with the newest installed Xcode. No Mac is required to compile. `BASE_BUNDLE_ID` stays the placeholder `com.example.sleeppause` until you change it.
